# Other Projects

## HerDefenders - AI Women's Safety System

Pose-based threat detection proof of concept using MediaPipe and OpenCV on CCTV footage, aimed at real-time monitoring and alerting. Founded by Tisha; approved by SSIP Gujarat and funded as a startup. Not currently active; code not public. (See the experience section of the core knowledge base.)

## Smart Multi-Agent Daily Planner

Team project of 3 (Tisha and two teammates), built after the Kaggle x Google 5-Day AI Agents Intensive. Three coordinated agents: Task Management (collect, prioritise, decompose), Scheduling (timeline, workload balancing, dynamic adjustment) and Execution (turn the schedule into actionable output).

## Smart Attendance System

Facial-recognition attendance marking using OpenCV and machine learning; shared as a 10-page LinkedIn document post.

## Data-Entry-Job-Automation

A course capstone from Angela Yu's "100 Days of Code". Beautiful Soup scrapes rental listings (price, address, link) for San Francisco from a Zillow clone, and Selenium fills a Google Form for each listing so the responses land in a Google Sheet.

https://github.com/tisha-varma/Data-Entry-Job-Automation

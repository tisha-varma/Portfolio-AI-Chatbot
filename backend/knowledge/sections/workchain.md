# Workchain - Decentralised Freelance Marketplace

Repository: https://github.com/tisha-varma/workchain

A decentralised application (DApp) on Ethereum that connects freelancers and clients through smart contracts: trustless escrow, dual client/freelancer roles, MetaMask wallet connection, an on-chain reputation system and a full task lifecycle (create, bid, deliver, review). Smart contracts track task status (Open, In Progress, Completed, Disputed) and access control.

Stack: Python 3.8+ with Flask, Web3.py, Solidity 0.8.0, Ganache local test network (chain ID 1337), MetaMask, SQLAlchemy with SQLite, flask-login, solcx.

The README notes the contracts are for local demos and need an audit before mainnet use.

Public repository, MIT license, 9 commits.
